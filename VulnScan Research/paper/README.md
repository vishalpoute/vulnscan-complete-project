# VulnScan Research Materials

Working research drafts and supporting templates for the VulnScan academic project.

## Files

| File | Purpose |
| --- | --- |
| `vulnscan_ieee.tex` | LaTeX paper draft using IEEE formatting |
| `vulnscan_paper.md` | Markdown paper draft |
| `SUBMISSION_GUIDE.md` | Submission preparation notes |
| `EXPERIMENTAL_RESULTS_TEMPLATE.md` | Template for recording evaluation results |
| `COMPLETION_VERIFICATION.txt` | Earlier preparation checklist |

## Editing and compilation

Keep the Markdown and LaTeX drafts consistent. To compile the LaTeX file, use a TeX distribution with the required IEEE class or import the sources into a LaTeX editor.

```sh
pdflatex vulnscan_ieee.tex
```

## Research status

These materials are drafts. Verify author details, citations, experiments and reported measurements before submission. Templates, checklist statements and intended architectural contributions do not establish completed evaluation, publication or acceptance by IEEE or Springer.

See the [complete project](../../README.md) for implementation context.
